# Hand-in Kit

A small, browser-local desk for preparing assignment attachments: sensible names, smaller scan images and one organised ZIP.

This project is being built for Stardance's Frictionless mission. It is separate from QueueClear, which organises tasks rather than files.

## Development

Node 22 or newer is enough. There are no npm dependencies or API keys.

```sh
npm start
npm test
npm run check
npm run build
```

The working app, manual test evidence and deployment instructions will be documented as the implementation is verified. This first milestone covers safe filename planning and the ZIP writer.

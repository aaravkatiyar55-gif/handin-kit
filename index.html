    SMALL DETAILS THAT MATTER

    Before pressing send.

    Names that travel well

    Numbering follows the order you choose. Duplicate names get a suffix, and each filename can be adjusted in the preview.

    Copies, never replacements

    Image processing happens on this device. The kit keeps your originals in memory so you can restore them before downloading.

    Read it once

    Size targets are best effort. Open the resulting attachments and check small text, page order and the recipient’s requirements.
